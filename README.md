## Brain Match Game 🧠🎮  
A sleek and addictive **memory matching game** built natively for iOS using **Swift**. Flip cards, match emojis, and test your memory power — all with smooth transitions and persistent gameplay!

### 🎮 Features  
- 🔄 Flip and match emoji pairs  
- 📊 Tracks matched pairs and current progress  
- 💾 Resume game from last saved state  
- 📋 Interactive in-app game rules sheet
