Brain Match Game is a simple and fun memory matching game where players flip cards to find pairs of identical emoji cards. The objective is to match all the pairs before the game ends. The game tracks your progress, displaying the number of matched pairs, and offers options to start a new game or resume a saved one.

Features
Flip and match emoji pairs.

Track matched pairs and game status.

Option to start, resume, or restart the game.

View game rules in an interactive sheet.
